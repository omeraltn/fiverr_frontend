# Fiverr Benzeri Hizmet Pazaryeri

Freelancer hizmetlerinin listelenip aranabildiği; kullanıcıların hizmet ekleyip detaylarını görüntüleyebildiği bir web uygulamasının istemci tarafıdır.

## Teknolojiler

React 19, TypeScript, Vite, Tailwind CSS 4, React Router, TanStack Query ve Axios.

## Yöntem

Arayüz yeniden kullanılabilir bileşenlere ve sayfalara ayrılmıştır. Veriler REST API üzerinden alınır; TanStack Query ile sunucu durumu yönetilir. Rotalar React Router ile, bildirimler React Toastify ile sağlanır.
